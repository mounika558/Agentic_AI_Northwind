NorthWind Agentic AI is an enterprise manufacturing assistant that uses an AI agent to understand natural-language user queries and intelligently select and execute the appropriate MCP tools.

The system connects a Streamlit conversational interface with an AI agent, MCP tools, FastAPI backend, and SAP HANA Cloud. The agent can retrieve enterprise information and perform business operations such as material lookup, sales-order analysis, customer summaries, ticket creation, and overdue-invoice analysis.
